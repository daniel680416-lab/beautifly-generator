# BEAUTIFLY 商品內頁文案與版型生成工具

專為 BEAUTIFLY 品牌設計的電商內頁排版與文案自動產生器。解決手機版圖片被拉長變形問題，並依據品類自動生成靜奢風（Quiet Luxury）文案與動態尺寸表。

## 🎯 核心功能

1. **直式圖片等比例防拉伸**：自動套用響應式等比縮放機制，手機端與電腦端皆不變形。
2. **六大商品品類切換**：
   - 運動內衣 (Sports Bra)
   - 上衣 (Tops / 罩杯上衣 / 瑜珈長短袖)
   - 瑜珈褲 (Leggings / 緊身褲 / 喇叭褲)
   - 套裝 (Sets / 兩件式運動套裝)
   - 罩衫外套 (Outerwear / 防曬外套)
   - 瑜珈配件 (Accessories)
3. **動態手動尺寸表**：支援自由增減尺寸與數值，並產生支援手機水平滑動的質感表格。
4. **雙欄位獨立輸出**：
   - **欄位 1：商品特性**（核心亮點、規格材質、尺寸指南、洗滌建議、預購與出貨說明）。
   - **欄位 2：商品內文**（品牌精神標語、直式大圖排版、三宮格細節解析、細節圖集、收尾引言）。
5. **所見即所得預覽**：支援切換「電腦版 (760px)」與「手機版 (390px)」預覽。

## 🚀 如何部署至 GitHub Pages（供員工使用）

1. 在 GitHub 上建立一個新的公開儲存庫（Repository），例如命名為：`beautifly-template-generator`。
2. 將本專案中的 `index.html` 上傳至該儲存庫的根目錄（`main` 或 `master` 分支）。
3. 前往 GitHub 儲存庫的 **Settings（設定）** ➔ 點選左側的 **Pages**。
4. 在 **Build and deployment** 下方的 **Branch** 選擇 `main`（或 `master`），資料夾保持 `/ (root)`，點擊 **Save**。
5. 等待 1~2 分鐘，上方即會出現專屬的線上網址（例如：`https://<your-username>.github.io/beautifly-template-generator/`）。
6. 將該網址提供給團隊同仁，即可在任何瀏覽器（手機或電腦）直接開啟使用！
